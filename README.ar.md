# shopping-cry

> 🌐 **Read in English:** [النسخة الإنجليزية (`README.md`)](README.md)

**لا تنخدع بكلام الإعلانات — اشترِ ما يثبت جودته فعلًا، في أي سوق حول العالم.**

يُحوّل **shopping-cry** أي مساعد ذكاء اصطناعي إلى مستشار تسوّق محترف: محرك رئيسي واحد (`product-scout`) ومعه 16 مهارة متخصصة تبحث في المنتج الذي تريده، وتقارن الأسعار الفعلية في بلدك وبعملتك المحلية، وتتحقق من الجودة عبر اختبارات معملية ومراجعات مستقلة، لتخرج في النهاية بقرار واضح ومباشر: ما الأفضل للشراء الآن، وما البديل الاقتصادي الأنسب لو ميزانيتك أقل، والحقيقة الصريحة إذا كانت ميزانيتك لا تكفي لمنتج جيد.

### لماذا يختلف عن البحث العادي؟

- **الأدلة قبل التسويق:** كل توصية مبنية على اختبارات معملية مستقلة ومراجعات خبراء، وليست مجرد نقل لمواصفات الشركة المصنّعة. ولو تضاربت المصادر، يخبرك بذلك صراحة.
- **قواعد أمان لا تقبل المساومة:** ضوابط صيدلانية دقيقة للأدوية والمكملات، شروط صارمة لمقاعد سيارات الأطفال، فحص مخاطر ملابس الأطفال، وعلامات إنذار مالية تحميك من الغش عند شراء الذهب والساعات.
- **صراحة كاملة حول الميزانية:** إذا لم تكن ميزانيتك كافية لشراء خيار جيد، لن يجملك بمنتج رديء؛ بل يصارحك فورًا ويوضح لك الفارق الذي ستحصل عليه بزيادة بسيطة.
- **يعمل في كل أسواق العالم:** غير مرتبط بدولة أو عملة معينة — يتكيّف تلقائيًا وقت البحث مع بلدك، وعملتك، ولغتك، والمتاجر والوكلاء المعتمدين لديك، والجهات الرقابية المحلية (مثل FDA وEMA وMHRA وTGA وHealth Canada أو ما يعادلها)، والجهد الكهربائي، ومعايير المقاسات، وطرق الغش الشائعة، ومواسم التخفيضات في سوقك.

## منظومة المهارات (17 مهارة)

| المهارة | مجال التخصص |
|---|---|
| `product-scout` (النواة الأساسية) | المنسّق الرئيسي وسير العمل العام: جمع احتياجاتك، اختيار عمق البحث، تنسيق المهارات المتخصصة، وإصدار الحكم النهائي مع بوابات الأمان |
| `product-scout-electronics` | الهواتف، اللابتوب، الشاشات والتلفزيونات، الصوتيات، الكاميرات، أجهزة الألعاب، الساعات الذكية، والإكسسوارات |
| `product-scout-beauty` | العناية بالبشرة والشعر، المكياج، العطور، والعناية الشخصية — تحليل المكونات العلمية وبروتوكولات العناية المتاحة بدون وصفة |
| `product-scout-clothing` | الملابس، الأحذية، والحقائب — تقييم المتانة والتكلفة مقابل عدد مرات اللبس، ملفات المقاسات، وتعلّم ذوقك بدون فرضه |
| `product-scout-health-medical` | الأدوية المتاحة بدون وصفة (OTC)، المكملات الغذائية، الأجهزة الطبية المنزلية، والإسعافات الأولية — بضوابط صيدلانية صارمة |
| `product-scout-appliances` | الأجهزة المنزلية الكبيرة والصغيرة — حساب استهلاك الكهرباء وفق التعريفة المحلية، شروط التركيب، وأمان الغاز والكهرباء |
| `product-scout-home-living` | الأثاث، أدوات المطبخ، المفروشات، الديكور، والإضاءة — أمان الخامات وتثبيت الأثاث لمنع الانقلاب |
| `product-scout-jewelry-watches` | الذهب، الألماس والأحجار الكريمة، والساعات — التحقق من الأصالة، الشهادات، وضوابط الحماية المالية |
| `product-scout-diy-garden` | العدد والأدوات اليدوية والكهربائية، مواد البناء، والحدائق — اقتصاديات البطاريات، معدات الحماية، وحدود العمل المنزلي الآمن |
| `product-scout-automotive` | قطع الغيار، الزيوت والسوائل، والإطارات — التحقق من التوافق مع السيارة أولًا، وفئة القطع الحرجة للأمان |
| `product-scout-groceries` | المواد الغذائية، المنتجات الطازجة، ومستهلكات المنزل — مقارنة سعر الوحدة الحقيقي وكشف الغش التجاري |
| `product-scout-pets` | طعام ومستلزمات الحيوانات الأليفة — التغذية المناسبة للعمر والنوع، مع فصل واضح لحدود الطبيب البيطري |
| `product-scout-baby-kids` | مقاعد السيارات، أدوات الرضاعة والتغذية، وتجهيزات غرفة الطفل — أعلى مستوى من قواعد الأمان في المشروع |
| `product-scout-toys-games-hobbies` | الألعاب حسب الفئة العمرية (كمعيار أمان)، ألعاب الطاولة، الآلات الموسيقية، والأشغال اليدوية |
| `product-scout-sports-outdoors` | معدات اللياقة، الرياضات الجماعية والمضرب، الدراجات، والتخييم — مع اشتراط معدات الحماية المعتمدة |
| `product-scout-books-media` | الكتب، المقررات الدراسية، والوسائط — مطابقة الطبعات ورقم ISBN ورفض النسخ المقرصنة |
| `product-scout-office-business` | الأدوات المكتبية، مستلزمات المدارس، ومشتريات المكاتب الصغيرة — التأكد من التوافق قبل السعر |

كل مجلد مهارة يحتوي على ملف `SKILL.md` وبجانبه المراجع العلمية والبيانات الموثّقة داخل مجلد `references/`. أما ملف `shopping-cry.md` الموجود في الجذر فهو نسخة مجمّعة للقراءة البشرية فقط، ويُعاد بناؤه تلقائيًا عبر `scripts/build-bundle.sh` — فلا تعدّله يدويًا (المساعدات الذكية تقرأ ملفات `skills/<name>/SKILL.md` الفردية مباشرة).

## التثبيت

### الطريقة الأولى — عبر Agent Skills CLI (لأي مساعد يدعمها)

</div>

```bash
npx skills add M7FX-1/shopping-cry
```

<div dir="rtl">

اختر المهارات التي تريدها أو ثبّت الـ 17 كاملة. يمكنك إضافة `-g` للتثبيت العام على الجهاز، أو `--list` لاستعراض القائمة أولًا.

### الطريقة الثانية — عبر سكربت التثبيت (لأي وكيل وبدون أي مكتبات إضافية)

</div>

```bash
git clone https://github.com/M7FX-1/shopping-cry
cd shopping-cry
./install.sh --dir ~/.agents/skills   # مثال: المسار العام لمهارات الوكلاء
./install.sh --dir /path/to/skills    # أو أي مسار خاص بالوكيل الذي تستخدمه
```

<div dir="rtl">

احرص على تثبيت النواة الأساسية (`product-scout`) مع التخصصات التي تحتاجها — التخصصات تتعرف تلقائيًا على النواة، وأي فئة غير موجودة في القائمة تعمل عبر سير العمل العام داخل النواة.

خيارات مفيدة للسكربت (أضف `FORCE=1` للكتابة فوق النسخ المثبتة مسبقًا):

</div>

```bash
./install.sh --list                                    # عرض الـ 17 مهارة المتاحة
./install.sh --only electronics,beauty --dir <root>    # تثبيت تخصصات محددة (النواة تُثبّت تلقائيًا)
./install.sh --check --dir <root>                      # مقارنة النسخ المثبتة لديك مع هذا المستودع
./install.sh --uninstall --dir <root>                  # معاينة الحذف (أضف --yes للتنفيذ الفعلي)
```

<div dir="rtl">

إلغاء التثبيت لا يمس أبدًا ملفاتك الشخصية المحفوظة في `~/.product-scout/profiles/`.

### الطريقة الثالثة — التثبيت اليدوي

انسخ المجلدات الموجودة داخل `skills/` مباشرةً إلى مجلد المهارات الخاص بالوكيل لديك، ثم أعد تشغيل الجلسة ليتعرّف عليها.

## ملاحظات مهمة

- **مرونة عالمية كاملة:** المشروع لا يقيّدك بدولة أو عملة أو متجر. القيم المرجعية (`[A]`) مضبوطة بما يعادل الدولار بعملتك المحلية وتُحدّث كل ~6 أشهر، بينما تُجلب الأسعار اليومية وتعريفات الكهرباء وأسعار الذهب لحظيًا وقت البحث حسب بلدك.
- **مسار التثبيت الصحيح:** يجب وضع المهارات مباشرة داخل مجلد المهارات (`<root>/<skill-name>/SKILL.md`)؛ وضعها داخل مجلد فرعي إضافي يمنع الوكيل من اكتشافها.
- **الفئات المحظورة:** التبغ، والتحايل على أنظمة الدعم، والبحث عن نسخ مقرصنة محظورة بالكامل كسياسات ثابتة داخل النواة.
- **خصوصية الملفات الشخصية:** ملفات التفضيلات (للبشرة والملابس والصحة) اختيارية تمامًا، لا تُنشأ إلا بموافقتك الصريحة، وتُحفظ محليًا على جهازك في `~/.product-scout/profiles/<name>.md` — وحذف الملف يزيل البيانات نهائيًا.
- **وسوم التحقق:** كل ملف `SKILL.md` يوضح في بدايته معنى وسوم الدقة `[S]` / `[P]` / `[A]`. شغّل `python3 scripts/validate.py` للتأكد من سلامة الملفات قبل رفع أي تعديل.
- **المقصود بـ `<skills-root>`:** هو مجلد المهارات الذي يقرأ منه الوكيل الذي تستخدمه (مثل `~/.agents/skills/`).
