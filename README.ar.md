# shopping-cry

**توقّف عن شراء التسويق. ابدأ في شراء ما يعمل فعلًا — في أي سوق حول العالم.**

يمنح **shopping-cry** أي مساعد ذكاء اصطناعي عقلية تسوّق متكاملة: محرك أساسي واحد (`product-scout`) بالإضافة إلى 16 مهارة متخصصة تبحث في مشترياتك، وتقارن الأسعار الحقيقية في بلدك وبعملتك المحلية، وتتحقق من الجودة بالاعتماد على اختبارات معملية مستقلة، ثم تعطيك قرارًا حاسمًا واحدًا — ماذا تشتري، وما البديل الأوفر إن كنت تريد إنفاق أقل، والحقيقة الصريحة عمّا لا يمكن لميزانيتك شراؤه.

**ما الذي يميّزه؟**

- **الدليل قبل التسويق.** التوصيات مبنية على اختبارات معملية مستقلة ومراجعات خبراء — وليس على أوراق مواصفات الشركات. وعندما تتضارب المصادر، يتم تنبيهك بوضوح.
- **حواجز أمان لا تتساهل.** حدود صيدلانية صارمة للأدوية والمكملات، قواعد مقاعد الأطفال بلا استثناءات، فحوصات أمان ملابس الأطفال، ومحفّزات انسحاب مالية للذهب والساعات.
- **صراحة كاملة بشأن المال.** إذا كانت ميزانيتك لا تشتري شيئًا جيدًا، يقول لك ذلك بوضوح — ويوضح لك ما الذي يمكنك الحصول عليه بزيادة بسيطة.
- **مصمم لكل أسواق العالم.** يعمل في أي دولة وبأي عملة وبأي لغة — ويتكيّف وقت البحث مع المتاجر والوكلاء المعتمدين في بلدك، والجهات الرقابية المحلية (FDA، EMA، MHRA، TGA، Health Canada أو ما يعادلها محليًا)، والجهد الكهربائي، ومعايير المقاسات والورق والأقراص، وفخاخ التقليد المحلية، ومواسم التخفيضات في سوقك.

## عائلة المهارات (17 مهارة)

| المهارة | التغطية |
|---|---|
| `product-scout` (الأساسية) | سير العمل العام والمنسّق الرئيسي: جمع المتطلبات، أوضاع البحث، هيكل الحكم النهائي، توزيع المهام، وبوابات الأمان |
| `product-scout-electronics` | الهواتف، اللابتوب، التلفزيونات، الصوتيات، الكاميرات، الألعاب، الأجهزة القابلة للارتداء، والإكسسوارات |
| `product-scout-beauty` | العناية بالبشرة، المكياج، العناية بالشعر، العطور، العناية الشخصية — علم المكونات وبروتوكولات OTC |
| `product-scout-clothing` | الملابس، الأحذية، الحقائب — المتانة وتكلفة الارتداء (CPW)، ملفات المقاسات، وتعلّم الذوق دون فرضه |
| `product-scout-health-medical` | أدوية OTC، المكملات الغذائية، الأجهزة الطبية المنزلية، الإسعافات الأولية — حدود أمان صيدلانية |
| `product-scout-appliances` | الأجهزة المنزلية الكبيرة والصغيرة — تكلفة التشغيل حسب تعريفة الكهرباء المحلية، التركيب، وأمان الغاز والكهرباء |
| `product-scout-home-living` | الأثاث، أدوات المطبخ، المفروشات، الديكور، الإضاءة — سلامة المواد وتثبيت الأثاث ضد الانقلاب |
| `product-scout-jewelry-watches` | الذهب، الأحجار الكريمة، الساعات — التحقق، الدرجات، وحواجز الأمان المالي |
| `product-scout-diy-garden` | العدد والأدوات، مواد البناء، الحدائق — اقتصاديات منصات البطاريات، معدات الوقاية (PPE)، وحدود الـ DIY |
| `product-scout-automotive` | قطع الغيار، الزيوت والسوائل، الإطارات — بروتوكول التوافق أولًا وفئة القطع الحرجة للأمان |
| `product-scout-groceries` | المواد الغذائية، الطازج، المستهلكات — حساب سعر الوحدة وفحوصات الغش التجاري |
| `product-scout-pets` | طعام ومستلزمات الحيوانات الأليفة حسب النوع — التغذية حسب المرحلة العمرية وحدود الطبيب البيطري |
| `product-scout-baby-kids` | مقاعد السيارة، الرضاعة والتغذية، غرفة الطفل — أقوى حواجز الأمان في العائلة |
| `product-scout-toys-games-hobbies` | الألعاب حسب العمر (تصنيف أمان)، ألعاب الطاولة، الآلات الموسيقية، والأشغال اليدوية |
| `product-scout-sports-outdoors` | اللياقة البدنية، الرياضات الجماعية والمضرب، الدراجات، التخييم — اشتراط الشهادات ومعدات الحماية |
| `product-scout-books-media` | الكتب، الكتب الدراسية، الوسائط — مطابقة الطبعات والـ ISBN ورفض القرصنة |
| `product-scout-office-business` | الأدوات المكتبية، مستلزمات المدارس، احتياجات الشركات الصغيرة — التوافق أولًا |

يحتوي كل مجلد مهارة على ملف `SKILL.md` بالإضافة إلى ملفات المراجع الموثّقة داخل `references/`. أما ملف `shopping-cry.md` في جذر المستودع فهو تجميعة لكل مهارات العائلة للقراءة البشرية فقط، ويُعاد توليده تلقائيًا عبر `scripts/build-bundle.sh` — لا تعدّله يدويًا أبدًا (الوكلاء يحمّلون ملفات `skills/<name>/SKILL.md` الفردية مباشرة).

## التثبيت

### الخيار 1 — عبر Agent Skills CLI (لأي وكيل يدعمه)

```bash
npx skills add M7FX-1/shopping-cry
```

اختر المهارات التي تريدها (أو ثبّت الـ 17 كاملة). أضف `-g` للتثبيت العام، أو `--list` للاستعراض أولًا.

### الخيار 2 — عبر سكربت التثبيت (لأي وكيل، بدون أي اعتمادات خارجية)

```bash
git clone https://github.com/M7FX-1/shopping-cry
cd shopping-cry
./install.sh --dir ~/.agents/skills   # مثال: المسار العام لمهارات الوكلاء
./install.sh --dir /path/to/skills    # مسار مهارات الوكيل الخاص بك — أي مسار
```

ثبّت المهارة **الأساسية** (`product-scout`) مع التخصصات التي تحتاجها — التخصصات تسجّل نفسها في جدول المهارة الأساسية، وأي فئة غير مسجّلة تعمل تلقائيًا عبر سير العمل العام في النواة.

خيارات إضافية: `FORCE=1 ./install.sh --dir <root>` للكتابة فوق المهارات المثبّتة مسبقًا.

```bash
./install.sh --list                                    # عرض الـ 17 مهارة القابلة للتثبيت
./install.sh --only electronics,beauty --dir <root>    # تثبيت مجموعة محددة (النواة تُثبّت دائمًا)
./install.sh --check --dir <root>                      # مقارنة النسخ المثبّتة مع هذا المستودع
./install.sh --uninstall --dir <root>                  # معاينة الحذف (أضف --yes للتنفيذ)
```

إلغاء التثبيت لا يمس أبدًا ملفاتك الشخصية في `~/.product-scout/profiles/`.

### الخيار 3 — التثبيت اليدوي

انسخ المجلدات الموجودة داخل `skills/` إلى مجلد المهارات الخاص بالوكيل لديك، ثم أعد تشغيل جلسة الوكيل ليعيد فحص المهارات.

## ملاحظات مهمة

- **تصميم عالمي متكيّف مع كل الأسواق:** لا توجد أي دولة أو عملة أو متجر أو جهة رقابية ثابتة في الكود. الحدود المرجعية (`[A]`) تعتمد على ما يعادل الدولار بعملتك المحلية وتُراجع كل ~6 أشهر، بينما تُجلب الأرقام الحية (أسعار المتاجر، تعريفات الكهرباء، سعر الذهب اليومي) وقت البحث حسب بلد المستخدم.
- يجب أن توضع المهارات المثبّتة **مباشرة** داخل مجلد المهارات الرئيسي (`<root>/<skill-name>/SKILL.md`) — وضعها داخل مجلد فرعي يمنع اكتشافها.
- الفئات المحظورة (التبغ، التحايل على أنظمة الدعم، ومصادر القرصنة) هي بوابات سياسة صارمة داخل النواة الأساسية وليست مهارات.
- الملفات الشخصية (للتجميل، الملابس، والصحة) اختيارية وتعمل بموافقة صريحة فقط، وتُحفظ محليًا في `~/.product-scout/profiles/<name>.md` — حذف الملف يمسح البروفايل بالكامل.
- وسوم التحقق `[S]` / `[P]` / `[A]` مُعرّفة مرة واحدة بعد العنوان في كل ملف `SKILL.md`. شغّل `python3 scripts/validate.py` قبل رفع أي تعديلات.
- المقصود بـ `<skills-root>` داخل نصوص المهارات هو مجلد المهارات الذي يفحصه الوكيل الخاص بك للعثور على ملفات `SKILL.md` (مثل `~/.agents/skills/`).
