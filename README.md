# shopping-cry

**Stop buying marketing. Start buying what works.**

shopping-cry gives any AI assistant a complete **global, multi-market**
shopping brain: one core engine plus 16 specialists (17 skills total) that
work across **all world markets**, in **any currency and any language**.
Each skill researches your purchase, compares real local prices, verifies
quality with independent lab evidence, and ends with one sharp answer — what
to buy, what to buy instead if you're spending less, and the truth about
what your money can't get.

**What makes it different**

- **Evidence over marketing.** Recommendations rest on independent lab tests
  and expert reviews — never vendor spec sheets. When sources conflict, you
  hear about it.
- **Safety rails that don't bend.** Pharmacist-grade medicine limits,
  car-seat rules with zero exceptions, child-garment hazard checks,
  financial walk-away triggers for gold and watches.
- **Honesty about money.** If your budget buys nothing good, it says so
  plainly — and shows what a little more would get instead.
- **Global & multi-market by design.** No country, retailer, or currency
  lock-in — all 17 skills work in any language and any local currency,
  adapting dynamically at runtime to your market's authorized retailers and
  service networks, local regulatory authorities (e.g., FDA, EMA, MHRA, TGA,
  or national equivalents), local mains voltage and regional standards
  (120V/60Hz or 220–240V/50Hz, car-seat standards, paper sizes, disc
  regions), local counterfeit traps, and local shopping and academic
  calendars.

## The family

| `product-scout` (core) | Generic research workflow + orchestrator: intake, modes, verdict structure, sub-agent dispatch, safety gates |

| `product-scout-beauty` | Skincare, makeup, haircare, fragrance, grooming — ingredient science, OTC treatment protocols |
| `product-scout-clothing` | Apparel, footwear, bags — durability & cost-per-wear, size profiles, style-taste learning |
| `product-scout-health-medical` | OTC medicines, supplements, home medical devices, first aid — pharmacist-grade limits |
| `product-scout-appliances` | Large & small appliances — energy cost, installation, gas/electrical safety |
| `product-scout-home-living` | Furniture, kitchenware, linens, decor, lighting — material safety, anchoring |
| `product-scout-jewelry-watches` | Gold, gemstones, watches — authentication, grading, financial-safety rails |
| `product-scout-diy-garden` | Tools, materials, gardening — platform math, PPE, DIY limits |
| `product-scout-automotive` | Parts, fluids, tires — fitment-first protocol, safety-critical parts tier |
| `product-scout-groceries` | Pantry, fresh, consumables — unit-price math, adulteration flags |
| `product-scout-pets` | Food & gear by species — life-stage feeding, vet-first medicine boundary |
| `product-scout-baby-kids` | Car seats, feeding, nursery — the family's strongest safety rails |
| `product-scout-toys-games-hobbies` | Toys by age (safety rating), games, instruments, crafts |
| `product-scout-sports-outdoors` | Fitness, team/racket sports, cycling, camping — certification co-purchase |
| `product-scout-books-media` | Books, textbooks, media — edition matching, piracy refusal |
| `product-scout-office-business` | Stationery, school supplies, B2B basics — compatibility-first |

Each skill folder contains `SKILL.md` plus its cited domain reference files
under `references/`. `shopping-cry.md` at the root is the whole family
bundled into one readable file, regenerated by `scripts/build-bundle.sh` —
never edit it by hand. For human reading only: agents load the individual
`skills/<name>/SKILL.md` files.

## Install

### Option 1 — Agent Skills CLI (Claude Code and other supported agents)

```bash
npx skills add M7FX-1/shopping-cry
```

Pick the skills you want (or accept all 17). Add `-g` to install globally,
or `--list` to browse first.

### Option 2 — Install script (any agent, zero dependencies)

```bash
git clone https://github.com/M7FX-1/shopping-cry
cd shopping-cry
./install.sh --zcode      # ZCode harness (~/.zcode/skills)
./install.sh --claude     # Claude Code (~/.claude/skills)
./install.sh --agents     # generic root (~/.agents/skills)
./install.sh --dir /path  # any custom skills root
```

Install the **core** (`product-scout`) together with the specialties you
want — the specialties register themselves in the core's specialty table and
fall back to the core's generic workflow for anything unregistered.

Flags: `FORCE=1 ./install.sh --zcode` overwrites already-installed skills.

```bash
./install.sh --list                          # show the 17 installable skills
./install.sh --only electronics,beauty       # install a subset (core always included)
./install.sh --check                         # compare installed copies with this repo
./install.sh --uninstall                     # preview removal (dry-run; add --yes to apply)
```

Uninstalling never touches your personal profiles in `~/.product-scout/profiles/`.

### Option 3 — Manual

Copy the folders inside `skills/` into your agent's skills root
(`~/.zcode/skills/`, `~/.claude/skills/`, or `~/.agents/skills/`), then
restart your agent session so it re-scans its skills roots.

## Notes

- The live/installed skills must sit **directly** under a skills root
  (`<root>/<skill-name>/SKILL.md`) — nesting them under a subfolder removes
  them from discovery.
- Restricted categories (tobacco, subsidy-system gaming, piracy sourcing) are
  policy gates in the core, never skills.
- Personal profiles (beauty, clothing, health) are opt-in, consent-gated, and
  stored locally at `~/.product-scout/profiles/<name>.md` — deleting one file
  erases one profile completely. Profiles created by older versions at
  `~/.zcode/product-scout/profiles/` are copied to the new location
  automatically on first use (one notification line; the original is left
  untouched).
- Verification tags `[S]` / `[P]` / `[A]` are defined once, after the title in
  every SKILL.md; `[A]`-tagged thresholds are calibrated anchors, re-anchored
  at install time on a ~6-month cadence. Run `python3 scripts/validate.py`
  before committing changes.
- `<skills-root>` in skill texts means your agent's skills root
  (`~/.zcode/skills/`, `~/.claude/skills/`, or `~/.agents/skills/`).
